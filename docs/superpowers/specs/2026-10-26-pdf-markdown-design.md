# PDF 转 Markdown

用户已选择统一使用 Microsoft MarkItDown。新增独立的 PDF → Markdown 模式，保留现有 Office → PDF 模式。PDF 模式递归扫描设置沿用界面，输出为原文件旁的同名 UTF-8 `.md`，始终保留 PDF，不移动源文件。复用逐文件结果、日志、取消、超时与失败重试。

备选方案：MarkItDown 依赖较轻，适合现有桌面工具；Docling、MinerU 提供模型辅助解析和 OCR，但增加安装与运行成本。本次采用用户选定的 MarkItDown，不接入其他引擎或云服务。

每次转换在独立进程执行，以便取消或超时时终止。先写临时文件，内容非空且转换成功后原子替换目标；扫描件无文字时明确失败，不覆盖已有输出。默认超时 120 秒，每文件失败后重试一次。重试绑定原任务模式与输出路径。

修改范围：新增 Markdown 后端、界面模式选择、PDF 可选依赖及打包收集配置、中英文文档与回归测试。验收覆盖真实文字 PDF、空白/损坏 PDF、中文路径、递归、失败隔离、取消、超时与原 Office 测试。
